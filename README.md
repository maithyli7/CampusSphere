# CampusSphere

A Django-based campus management portal designed to provide students and administrators with a centralized platform for managing academic and campus-related information.

## Features

- Student login and registration
- Student dashboard
- Campus notices
- Events and announcements
- Study materials
- Lost & Found section
- Academic calendar
- Admin dashboard
- Secure access to student features

## Tech Stack

- **Backend:** Python, Django
- **Frontend:** HTML, CSS
- **Database:** SQLite
- **Version Control:** Git & GitHub
